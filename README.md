# VPOverview

Patientöversikt för PDT-behandlare, med data från Kaddio.

## Installera

1. Öppna [senaste versionen](https://github.com/manumahal/vpoverview-releases/releases/latest)
   och ladda ner filen som slutar på **`_x64-setup.exe`**.
2. Kör filen. Windows kan visa **"Windows skyddade datorn"**. Klicka **Mer info** och
   sedan **Kör ändå**. Det beror på att programmet inte är signerat med ett köpt
   certifikat.
3. Ingen administratörsbehörighet behövs. VPOverview hamnar i startmenyn.

Första gången programmet startar öppnas inställningarna. Låt den som är ansvarig för
VPOverview fylla i dem tillsammans med dig. Du får din egen API-nyckel. Den skickas
inte via mejl eller chatt.

## Uppdatera

Det sker automatiskt. När det finns en ny version visas en grön knapp,
**Ny version …**, uppe till höger i programmet. Klicka på den, så startar programmet
om med den nya versionen. Dina inställningar och markeringar finns kvar.

## Avinstallera

**Inställningar → Appar → VPOverview → Avinstallera.**
Kryssa i rutan för att **ta bort programdata** om allt ska bort, även inställningar
och API-nyckel.

---

Här finns bara installationsfilerna. Programmet sparar inga patientnamn eller
personnummer på datorn.
